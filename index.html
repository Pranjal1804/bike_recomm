Mathematical Foundation

5 Models. One Perfect Decision.

Each model evaluates bikes from a different mathematical perspective. The final recommendation is an ensemble of all five.

📐
01

TOPSIS

Technique for Order Preference by Similarity to Ideal Solution

Ranks bikes by measuring their distance from the ideal best and worst solutions in normalized decision space.

Ci = d−i / (d+i + d−i)
Weight: 25%
⚖️
02

AHP

Analytic Hierarchy Process

Derives criterion weights from pairwise comparisons using eigenvector analysis, ensuring mathematically consistent priorities.

w = emax / Σemax
Weight: 25%
🌊
03

Fuzzy Logic

Linguistic Variable Inference System

Handles imprecise user preferences using membership functions, converting vague terms like "affordable" into crisp scores.

μ(x) = max(0, min(1, (x−a)/(b−a)))
Weight: 20%
🎯
04

K-NN

K-Nearest Neighbors Similarity

Finds the K most similar bikes to user preferences using Euclidean distance in normalized feature space.

d(p,q) = √Σ(pi − qi)²
Weight: 15%
📊
05

WSM

Weighted Sum Model

Computes a single composite score by multiplying normalized attribute values with their respective importance weights.

Si = Σ wj · aij
Weight: 15%
